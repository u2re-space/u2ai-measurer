---
name: House style
description: The conventions of the project the pictures belong to.
roles: measurer, designer
---

The project uses a 4px spacing grid and a 16px root font size.

- Round every spacing value to the nearest multiple of 4px; write it in rem (4px = 0.25rem).
- The only border radius in the system is 8px, except for the pills, which are 999px.
- The accent colour is reserved for the call to action; never use it for a decoration.
- The body text is 16px/1.5, the captions are 13px/1.4.
